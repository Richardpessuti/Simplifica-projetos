Configuração única. Pra essa página conseguir salvar a lista direto no repositório, você precisa criar um token de acesso do GitHub, restrito só a este repositório. Leva 1 minuto:
  1. Abra github.com/settings/personal-access-tokens/new (logado como Richardpessuti).
  2. Em Repository access, marque "Only select repositories" e escolha Simplifica-projetos.
  3. Em Permissions → Repository permissions, ache Contents e mude pra Read and write.
  4. Clique em Generate token lá embaixo, e copie o token gerado (começa com github_pat_).
Fica salvo só neste navegador (não sai daqui, não é enviado pra nenhum outro lugar além do GitHub). Se trocar de celular/navegador, precisa colar de novo.
